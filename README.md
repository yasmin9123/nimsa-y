# NIMSA-Y — GitHub Pages MVP

A no-backend, launch-ready prototype for NIMSA-Y: a model rocket design and simulation concept.

## What is included
- Landing page
- Interactive rocket geometry controls
- Live rocket preview
- Simplified apogee, velocity, flight-time, and stability estimates
- Altitude-vs-time visualization
- Rule-based design review
- Responsive layout

## Fastest GitHub Pages deployment
1. Create a public GitHub repository named `nimsa-y`.
2. Upload **index.html**, **styles.css**, and **script.js** to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.
7. The site will appear at `https://YOUR-USERNAME.github.io/nimsa-y/`.

## Important
The current physics is intentionally simplified for an MVP and should not be represented as certified flight simulation. A later version can connect to a more rigorous physics engine, OpenRocket-compatible data, weather inputs, saved projects, and a true AI design assistant.
